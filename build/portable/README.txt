Task Flow — portable version for Windows (x64, Windows 10 or later)

ЗАПУСК
1. Распакуйте весь ZIP-архив в любую папку (например, «Документы\Task Flow»).
2. Дважды щёлкните «Task Flow.bat».
Node.js, npm и установка не нужны.

ДАННЫЕ
Задачи и настройки ИИ хранятся в папке %APPDATA%\Taskflow, а не рядом с программой,
поэтому папку программы можно перемещать или заменять новой версией без потери задач.
API-ключи хранятся в зашифрованном виде (защита Windows) и расшифровываются только
под вашей учётной записью Windows на этом компьютере. На другом компьютере ключ
нужно ввести заново.

ПРЕДУПРЕЖДЕНИЕ WINDOWS
Программа не подписана цифровой подписью. Windows SmartScreen может показать
предупреждение («Подробнее» → «Выполнить в любом случае»), а включённый
Smart App Control может заблокировать запуск.

-----------------------------------------------------------------------------

START
1. Extract the whole ZIP archive to any folder (for example "Documents\Task Flow").
2. Double-click "Task Flow.bat".
No Node.js, npm or installation is needed.

DATA
Tasks and AI settings are stored in %APPDATA%\Taskflow, not next to the program, so the
program folder can be moved or replaced with a newer version without losing tasks.
API keys are stored encrypted (Windows data protection) and can only be decrypted by your
Windows account on this PC. On another PC, enter the key again.

WINDOWS WARNING
The program is not code-signed. Windows SmartScreen may show a warning
("More info" -> "Run anyway"), and Smart App Control, if enabled, may block it.
